# Compare Old Estimate to New Documents Workflow

Use this workflow when comparing an older estimate against a newer drawing/specification package to determine whether the old estimate is still valid, incomplete, outdated, or needs a full rewrite.

This workflow is especially useful when a project has an older PER, prior design estimate, legacy spreadsheet, or estimate written in the wrong format.

Use this workflow together with:

- `../global-estimating-instructions.md`
- `../hms-style-guide.md`
- `../alaska-pricing-guidelines.md`

---

## Purpose

The purpose of this workflow is to compare an old estimate against newer project documents and identify:

- Scope that still applies
- Scope that changed
- Scope that was deleted
- Scope that is newly added
- Scope that was missed in the old estimate
- Scope that is duplicated
- Scope that needs reformatting
- Scope that needs repricing

The output should help an estimator decide whether to update the old estimate, use it only as a reference, or rebuild the estimate from the new design documents.

---

## Required Inputs

Use all available information:

- Old estimate workbook or PDF
- Old drawings or specs if available
- New drawings
- New specifications
- New narratives
- Addenda
- Alternates
- Owner comments
- Engineer comments
- Quantity lists
- Known design changes
- Project location
- Design level of old estimate
- Design level of new documents

If the old documents are not available, compare the old estimate directly against the new documents and flag the limitation.

---

## Initial Classification

Before line-by-line review, classify the relationship between the old estimate and new documents.

Use one of the following:

| Classification | Meaning |
|---|---|
| Minor Update | Same general design; quantities or details changed |
| Moderate Update | Same project concept; several systems changed |
| Major Redesign | Old estimate is useful only as partial reference |
| New Design | Old estimate should not be treated as a reliable baseline |
| Format Rewrite | Scope may be similar, but estimate organization must change |
| Unknown | Insufficient information to classify |

If the new design is effectively a new design, say so clearly.

---

## Comparison Procedure

### Step 1: Map Old Estimate Sections

Create a quick scope map of the old estimate:

- Division or section
- Subsection
- Major scope items
- Quantities
- Units
- Alternates
- Allowances
- Assumptions
- Exclusions

### Step 2: Map New Documents

Create a scope map of the new documents:

- Drawing disciplines
- Specification sections
- Schedules
- Details
- Narratives
- Alternates
- Phases
- Owner or engineer comments

### Step 3: Match Scope

For each old estimate line or section, classify the new condition:

| Old Estimate Scope | New Document Condition | Result |
|---|---|---|
| Still shown with similar quantity | Valid / minor update |
| Still shown with changed quantity | Revise quantity |
| Still shown with changed spec | Revise pricing / description |
| Not shown | Delete or verify |
| Moved to alternate | Move out of base scope |
| Replaced by new system | Delete old and add new |
| Too broad | Break into detailed lines |
| Duplicated elsewhere | Combine or remove duplicate |

### Step 4: Review New Docs Independently

After matching old lines, review the new documents without relying on the old estimate.

Look for scope that is shown in the new documents but not in the old estimate.

---

## Change Categories

Use these categories in the comparison output:

| Category | Use |
|---|---|
| Keep | Old line still valid |
| Revise | Existing line needs quantity, description, or pricing update |
| Add | New scope not found in old estimate |
| Delete | Old scope no longer appears required |
| Move | Scope moved to alternate, phase, or different section |
| Split | Old line should be broken into multiple lines |
| Combine | Duplicate or overlapping lines should be combined |
| Verify | Documents do not provide enough certainty |

---

## Missed Scope Review

Check the new documents for items commonly missed in old estimates:

- Demolition and removals
- Temporary work
- Bypass pumping
- Erosion control
- Dewatering
- Testing and inspection
- Commissioning
- Startup
- Controls / SCADA
- Electrical support for mechanical equipment
- Heat trace
- Insulation
- Coatings
- Surface restoration
- Utility reconnections
- Owner training
- Spare parts
- Closeout requirements
- Freight and handling
- General Requirements
- Mobilization / demobilization

---

## Pricing Relevance Review

Old unit pricing may not be valid if:

- The estimate is several years old
- Material market changed
- Labor assumptions changed
- Freight assumptions changed
- Project location assumptions changed
- Scope is now more detailed
- Design requirements changed
- Funding compliance requirements changed
- Construction season changed

Flag pricing that should be escalated, repriced, or replaced.

## Alaska Pricing Check

When comparing old estimates to new documents, verify whether the old estimate included:

- Material base cost
- Shipping / freight
- Handling
- Remote delivery premium
- Anchorage labor rates or project-specific rates
- Productivity factors
- Travel and lodging
- Mobilization / demobilization
- Seasonal impacts
- Escalation

If not, flag the old estimate as underdeveloped for Alaska conditions.

---

## Final Recommendation

End the review with a clear recommendation:

- Update old estimate directly
- Use old estimate as partial reference only
- Rebuild estimate from new documents
- Reformat old estimate before updating
- Request clarification before pricing specific scope

Include a short reason.

Example:

```text
Recommendation: Rebuild estimate from the new 65% documents. The old PER estimate is useful for historical scope reference only because the new design changes the major wastewater treatment approach and reorganizes alternates.
```

---

## Final Deliverable

The final comparison should include:

1. Overall classification
2. Summary matrix
3. Line-by-line change log
4. Added scope list
5. Deletion candidates
6. Pricing relevance notes
7. Alaska logistics / freight concerns
8. Final recommendation

The goal is to make the estimate transition traceable and prevent important scope from being lost or duplicated.
