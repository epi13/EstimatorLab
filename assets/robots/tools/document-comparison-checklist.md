# Document Comparison Checklist

Use this checklist when comparing project documents against an existing estimate, prior design package, old PER, revised drawing set, updated specification book, addendum, or supplemental quantity list.

This checklist is intended for LLM-assisted estimating work in EstimatorLab.

Use this checklist together with:

- `../global-estimating-instructions.md`
- `../hms-style-guide.md`
- `../alaska-pricing-guidelines.md`
- `../workflows/compare-old-estimate-to-new-docs.md`
- `../workflows/update-estimate-design-level.md`

---

## Purpose

The purpose of this checklist is to make document comparison systematic and traceable.

When comparing old and new documents, the goal is to identify:

- Added scope
- Deleted scope
- Revised scope
- Scope moved to an alternate
- Scope moved to another phase
- Scope shown in drawings but missing in specs
- Scope required by specs but not obvious in drawings
- Estimate lines that no longer match the documents
- Quantity changes
- Pricing basis changes
- New assumptions or clarifications needed

---

## Comparison Inputs

Collect and identify all available inputs:

- Prior estimate
- Prior drawings
- Prior specifications
- Prior narratives
- New drawings
- New specifications
- New narratives
- Addenda
- Alternates
- Owner comments
- Engineer comments
- Quantity lists
- Meeting notes or email direction
- Design level of each package
- Project location

If older source documents are unavailable, compare the old estimate directly against the new documents and flag that limitation.

---

## Initial Comparison Questions

Before detailed review, answer:

1. What is the old design level?
2. What is the new design level?
3. Is the estimate format changing?
4. Is the new design an incremental update or a major redesign?
5. Were alternates added, removed, or redefined?
6. Did scope move between base bid and alternates?
7. Did scope move to another phase?
8. Are owner-furnished and contractor-furnished scopes defined?
9. Are there new funding or compliance requirements?
10. Are there new Alaska logistics assumptions?

---

## Comparison Classification

Classify the overall comparison:

| Classification | Meaning |
|---|---|
| Minor Revision | Same design; limited quantity/spec updates |
| Moderate Revision | Same concept; several systems or quantities changed |
| Major Redesign | New documents materially change project scope or approach |
| Format Conversion | Scope may be similar but estimate format must change |
| New Scope Package | Old estimate is only background reference |
| Insufficient Information | Documents are not complete enough to classify |

State this classification before listing detailed changes.

## Scope Change Categories

Use the following categories for detailed comparison:

| Category | Definition |
|---|---|
| Added | New scope appears in latest documents |
| Deleted | Prior scope no longer appears required |
| Revised | Size, material, quantity, location, or construction method changed |
| Moved | Scope moved to another section, phase, or alternate |
| Split | Prior broad scope should be broken into multiple items |
| Combined | Prior separate items are now one system or package |
| Unchanged | Scope appears generally consistent |
| Conflict | Documents disagree |
| Verify | More information needed |

- Drawing shows demolition not described in specs.

## Final Checklist

Before completing a document comparison, verify:

- All available documents were considered.
- Old estimate scope was mapped.
- New document scope was reviewed independently.
- Added scope is listed.
- Deleted scope is listed.
- Revised scope is listed.
- Alternates are separated.
- Conflicts are flagged.
- Quantity changes are shown.
- Alaska logistics impacts are considered.
- Recommendations are actionable.
