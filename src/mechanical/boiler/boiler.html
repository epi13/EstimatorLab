Notes / Logic
Material boiler cost scales non-linearly with size (smaller units have higher $/MBH). Zones add circulators/valves. Venting cost is based on vent type. Controls escalate with tier. Shipping assumes the base freight/handling percentage set above, multiplied by remoteFactor.
Labor hours are based on Anchorage baseline plus remote handling factor. Demo adds removal hours. After Hours adds 20% labor premium. Mechanical labor rate comes from the pricing inputs.
This is a budgetary tool, not stamped engineering. For steam boilers, different code path (not included).
